# AI-Augmented Student CGPA Performance Management System

## 1. Introduction
The Student CGPA Performance Management System is a Python-based application developed to calculate a student's CGPA and determine their academic performance category.

## 2. Objectives
- To calculate CGPA using grade points and subject credits.
- To validate input data and handle invalid values.
- To classify academic performance based on CGPA.
- To implement automated testing using pytest.
- To maintain code quality using Black and Ruff.

## 3. Technologies Used
- Python 3.12
- Visual Studio Code
- Git and GitHub
- pytest
- pytest-cov
- Black
- Ruff

## 4. Project Structure
- `src/` — Application source code
- `tests/` — Automated test cases
- `config/` — Configuration files
- `docs/` — Project documentation
- `pyproject.toml` — Tool configuration
- `.gitignore` — Files excluded from version control

## 5. Testing
Automated tests were executed using pytest.

**Test result:** 8 tests passed.

Code coverage was measured using pytest-cov.

**Measured code coverage:** 74%.

## 6. Code Quality
Black was used for code formatting, and Ruff was used for linting.

## 7. Conclusion
The project demonstrates Python programming, input validation, automated software testing, code quality checks, version control, and GitHub integration.
